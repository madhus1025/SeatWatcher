Seat Watcher Companion

One-time installation for Chrome or Microsoft Edge. The extension checks BookMyShow through this computer while your private watchlist remains in Azure.

  1. Keep this extracted folder in a permanent location. Do not delete it after loading the extension.
  2. Open chrome://extensions in Chrome or edge://extensions in Edge.
  3. Enable Developer mode in the top-right corner.
  4. Click Load unpacked and select this folder—the one containing manifest.json.
  5. Pin Seat Watcher Companion from the browser's Extensions menu.
  6. Sign into the Seat Watcher website, generate a pairing code, open the extension, paste it, and click Connect extension.
Monitoring requirement: keep Chrome or Edge running. The extension checks once per minute and displays a desktop notification when matching seats become available.

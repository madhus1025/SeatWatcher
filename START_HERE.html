Fresh-device setup

Seat Watcher in 6 steps

Everything needed to install, start, and use the local BookMyShow watcher. No Azure account, BookMyShow login, API token, or coding experience required.

✓ Runs privately on this computer
0 of 6 complete
💡
Keep the terminal window and this computer running while monitoring.

The local watcher checks BookMyShow through your normal internet connection. Closing the terminal or putting the computer to sleep pauses monitoring.

1

Extract this ZIP

Move the ZIP to a convenient place such as Downloads or Documents, then extract it.

  • Double-click the ZIP.
  • Open the new Seat-Watcher-Local folder.
  • Right-click the ZIP and choose Extract All….
  • Click Extract, then open Seat-Watcher-Local.
  • Use your file manager's Extract Here option.
  • Open the extracted Seat-Watcher-Local folder.
2

Install Node.js 22 LTS

Node.js runs the watcher. Download the LTS installer from nodejs.org/en/download and accept the installer defaults.

Already have Node.js? Open a terminal and run node --version. If it starts with v22 or newer, continue.
node --version
3

Open a terminal in the app folder

In Finder, open Seat-Watcher-Local. Right-click the folder background and select New Terminal at Folder. If that option is hidden, open Terminal and type cd , drag the folder into Terminal, then press Return.

Open Seat-Watcher-Local in File Explorer. Click the address bar, type powershell, and press Enter.

Open Seat-Watcher-Local in your file manager, right-click the background, and choose Open in Terminal.

Your terminal should now show the extracted Seat-Watcher-Local folder as its current location.
4

Install the app and Chromium

Run these commands one at a time. This is required only once on a new device or after replacing the app folder.

npm ci
npx playwright install chromium
npx playwright install --with-deps chromium
Wait until both commands finish and the prompt returns. Browser downloads can take several minutes.
5

Start Seat Watcher

Run the following command. Leave this terminal window open while monitoring.

npm start

When you see BMS Seat Watcher web listening on :8080, open:

http://localhost:8080
Future launches: open a terminal in this folder and run only npm start. Stop the app at any time with Ctrl + C.
6

Add a show and enable alerts

In Seat Watcher, click Enable sound and allow browser notifications/audio if asked.
On BookMyShow, choose the city, movie, date, theater, showtime, and number of tickets.
When the seat map opens, copy the full URL containing /seat-layout/.
Paste it into Seat Watcher, enter rows and seats needed, then click Start watching.
Use the Test alarm button once. Keep the Seat Watcher tab open and prevent the computer from sleeping so the alarm can reach you.
🎉

Setup complete

Your local Seat Watcher is ready. Add a show, keep the terminal open, and let it watch the seats.

Quick troubleshooting

“node” or “npm” is not recognized

Finish installing Node.js 22 LTS, close all terminal windows, then open a new terminal and try again.

Chromium executable is missing

Run npx playwright install chromium from the app folder. On Linux, use npx playwright install --with-deps chromium.

localhost:8080 does not open

Confirm the terminal running npm start is still open and has no red error. If another app uses port 8080, stop it or start with PORT=8081 npm start on macOS/Linux. In PowerShell, use $env:PORT=8081; npm start.

The watch says the seat canvas did not render

Open the same URL in your normal browser. Ensure the show is still in the future and the seat map appears. If BookMyShow changed the session, copy a fresh seat-layout URL.

No alarm sound

Click Enable sound, then Test alarm. Keep the tab open, raise the system volume, and make sure the browser tab is not muted.

Where is my watchlist stored?

It is stored locally in watches.json, created beside the app after first use. Do not replace that file if you want to retain your watchlist.
